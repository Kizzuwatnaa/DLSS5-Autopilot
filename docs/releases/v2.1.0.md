# DLSS 5 Autopilot 2.1.0

Updating from 2.0.x with **update now** downloads this build, checks its
SHA-256 against the `SHA256SUMS.txt` published with the release, and offers
a one-click restart. Your settings, library, hidden games and profiles carry
over.

## Added

- **gitc-uplift, a route for every API** (#946). ghostinthecamera's
  GITC-Uplift is one ReShade add-on that runs the network itself, on the
  finished frame or inside the game's own DLSS, for Direct3D 9 to 12,
  Vulkan and OpenGL games, 32- and 64-bit (a 64-bit helper serves 32-bit
  games). The install checks every file against the SHA-256 list the
  release publishes, puts `nvngx_dlssnr.dll` in a `GITC-Uplift` folder
  beside the add-on and moves one found beside the executable aside (on
  RTX 50 NVIDIA's DLSS would load that one first). It starts switched
  off: **Home**, the GITC Uplift tab, **Enable**. **did it work?** reads
  its own `[Uplift]` lines in ReShade.log. It is in the route list beside
  the others; auto, the shared results and **autopilot** never pick it.
- **One card for the last session.** The game page shows what the last
  session came to in one place: the diagnosis' own headline, its findings,
  and the route the watcher offers when it did not work. Where the logs
  carry a number it is printed with it - the model's cost a frame and the
  work area on the optiscaler route, the frame rate and frame count on the
  feeder. A session the logs cannot judge is not shown as a failure.
- **model passes on the pre-SR OptiScaler builds** (#957). With wilsjo2's
  or Janblade's build chosen under **optiscaler build**, a **model passes**
  dropdown offers auto, 2x and 3x and writes `Passes` into `[DlssNr]` of
  OptiScaler.ini. Each pass runs the whole model again on its own output:
  2x costs about twice the model's time, 3x three times.
- **keep its own** on the dlss page. A game marked this way is left out of
  **update all**, shows "kept by you", and asks first when it is updated by
  hand; **allow updates** takes it back (#856).

## Changed

- **A bug report never arrives empty.** **report a bug** saves the whole
  report to a file first, puts it on the clipboard and reads it back, and
  the link carries the longest start of it that fits. One line says which
  of those happened. **copy report** and **save zip** stay available; the
  zip holds the report and the logs it was built from (the last 4 MB of
  each).
- **Call of Duty counts as anti-cheat.** RICOCHET leaves no file of its own
  beside `cod.exe`, so Call of Duty titles were treated as ordinary games
  and taken into **update all** (#856). They are left out and ask first,
  and a DLSS 5 install on one gets the anti-cheat warning.
- The RTX 40 multi-frame generation extra installs Ultimate ASI Loader
  9.7.4, the release it was run with; 10.0 changed the loader.
- **Mafia II: Definitive Edition** gets `DirectNeuralRenderingHookStage=0`
  on the renodx route, so the game starts with the hook off; a stage set by
  hand is left alone. Switch neural rendering on in the overlay once the game is
  running (#808, #886).

## Fixed

- A 64-bit DirectX 9 game on the renodx-dlss route got ReShade as
  `dxgi.dll`, which a DirectX 9 game never loads (#77, #171). Routes that do
  not go through DXVK put it in as `d3d9.dll`.

- An Unreal starter executable (a few dozen modules, no graphics DLL) is
  named as one, with the executable that draws when the folder holds one
  (the `-Win64-Shipping.exe` under `Binaries\Win64`), instead of "try
  another proxy name" (#850, #874).
- A protected executable in any folder gets the architecture and graphics
  api choice; outside `C:\XboxGames` and `WindowsApps` it showed
  "Cannot read ... [Errno 13]" with install switched off (#897).
- A crash the feeder records inside a mod's `.asi` names that file, and the
  feeder 1.19 wording (`EXCEPTION RECORDED`) is read (#562).
- The bridge counting no DLSS call at all (an emulator such as RPCS3) is
  answered with the bridge panel and the feeder route, which draws its own
  frame and needs no call, instead of "turn DLSS on in the game's menu"
  (#862).
- Another add-on that ran in ReShade beside ours is named, also when the
  only trace of it is its own lines in `ReShade.log`, and it comes first in
  what to take out when the game never started. Plain `.addon` files (Luma
  mods) and 32-bit `.addon32` files count as add-ons in the folder (#944).
- The bug report keeps the lines the diagnosis decides on: ReShade's
  Direct3D 9 / swap-chain lines in a log full of warnings (#823), and the
  helper's "evaluate raised" line that the driver-fault answer needs (#917).
- GITC-Uplift's files in a game folder are named as another DLSS hook (it
  does not run beside another neural add-on).
